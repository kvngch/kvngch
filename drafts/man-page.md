KVNGCH(1)                 User Commands                 KVNGCH(1)

NAME
     kvngch - Kévin Gachie, software developer in Marseille

SYNOPSIS
     kvngch [--business-app] [--mobile] [--desktop]
            [--e-commerce] [--cms] [PROJECT ...]

DESCRIPTION
     Handles the technical side of E-Corp, a development studio,
     and builds the products it publishes.

OPTIONS
     --business-app
            Scheduling, activity tracking, back offices, client
            portals: the tools a company runs on day to day.
            TypeScript and React on the front, Node or PHP
            behind, PostgreSQL underneath.

     --mobile
            iOS and Android, native or cross-platform. Swift on
            one side, Kotlin and Jetpack Compose on the other,
            with on-device processing and offline use when the
            context calls for it.

     --desktop
            Native applications for macOS and Windows, in Swift
            and .NET, plus Tauri when a web core suits the
            product.

     --e-commerce
            WordPress and WooCommerce, PrestaShop, and custom
            development on Shopify. Themes and apps, catalogue
            and inventory sync, marketing and ads gateways, ERP
            connections.

     --cms  WordPress, including custom plugin development, and
            Joomla on the classic side. Headless where it fits:
            Sanity for the content, Astro for the front end.

ENVIRONMENT
     STACK  TypeScript React Next.js Astro Node PHP Laravel
            Python Swift Kotlin Compose .NET Tauri WordPress
            WooCommerce Joomla Sanity PrestaShop Shopify
            PostgreSQL Docker

FILES
     ~/.config/kvngch/studio      the agency
     ~/.config/kvngch/site        the personal one

SEE ALSO
     ecorp-agency(7), kvngch(7), linkedin(7)

Marseille                     2026                      KVNGCH(1)
